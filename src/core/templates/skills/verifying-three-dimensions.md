# forge verifying-three-dimensions

骨架占位,Task 2 填充完整协议。

本 skill 用于验证 forge 变更的完整性、正确性和连贯性三个维度,产出具有证据和严重级别的 verify_findings,而非简单的 pass/fail 二元判断。沿 design §2.2 协议落地,支持 Completeness / Correctness / Coherence 三维度分析。
